# Changelog

## 0.4.0 — 2026-10-16

- 首次见面先交付价值：系统提示按状态动态出现（档案为空时先做交易体检或市场雷达、实盘持仓没有足量止损时列为最高优先、连亏 3 笔时建议冷静期），并附一张交易卡模板；整段约 1000 token。
- 新增交易体检 `hyper_account action=analyze`：按完整往返统计胜率、盈亏比、期望、持仓时长，按币种 / 时段 / 星期拆分，计入手续费与资金费，并按金额列出习惯问题和建议规则；少于 10 笔往返时不下结论。
- 新增市场雷达 `hyper_market action=scan`：扫描成交额最大的核心永续与 HIP-3，给出贴近 / 突破 20 根已收盘 1h 区间、资金费极值、24h 涨跌与溢价的前几名。
- 价格提醒触发时唤醒画线所属会话的 agent（只复核和告知；去重、5 秒合并、5 分钟冷却、过期丢弃；被提醒唤醒的一轮不能下单、改限额或划转）。修复 HIP-3 市场的价格提醒从不触发。
- 在交易台「签名与托管」中连接钱包：选择签名方式、dsh-web3 账户并填写主账户地址，保存后立即生效，无需重启宿主，并在重启后保留。
- 对话栏快捷入口改为：交易体检、今天有什么机会、帮我盯着仓位、把图上画线变成策略。
- 行情实时更新不再整批重设序列、不再重建画线坐标映射，翻译函数缓存语言；5000 根 K 线 + 100 条画线下实时更新的 p95 帧耗时由 133ms 降到 16.7ms。
- 研究多图首次加载时以联动范围为准，修复完整流程中的时间联动失败。
- 新增 `docs/agent-evals.md` 评测场景与评分表。

### 0.3.1 中的改动（未单独发布）

- 增加半托管 / 全托管切换，实盘开启全托管需要明确确认，并持久保存选择。
- 支持 USDC 保证金的 HIP-3 永续交易，以及主永续账户与 HIP-3 之间的 USDC 划转。划转必须使用与交易地址一致的主钱包；API wallet 不能签署此类划转。
- 增加跨会话的交易员档案、策略库和交易日志。战绩按策略版本、网络及 paper / live 分开统计；旧的无版本记录保留在 unknown 历史分组。
- 重写交易 skill，补齐托管边界、保证金管理和策略迭代流程。
- 将交易限额弹窗分为交易限额、模拟成本、签名与托管三个标签页，分别保存设置。
- 优化画线列表、数字格式化、隐藏指标更新和画线坐标投影，减少高频行情与图表手势引起的重复工作。
- 修复划转期间切换网络 / 模式 / 托管状态、签名地址不一致，以及取消后仍提交划转的问题。
- 修复 HIP-3 风控的保证金范围：Standard 按独立交易所检查，Unified 按同一抵押资产汇总新鲜仓位；Portfolio Margin 仍采用保守的 USDC 权益估值。
- 补充托管确认、弹窗标签页独立保存、跨版本战绩及资金划转回归测试；性能冒烟明确区分图表平移与画线拖动，并独立采样各阶段帧耗时。
