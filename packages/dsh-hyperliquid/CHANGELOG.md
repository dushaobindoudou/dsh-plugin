# Changelog

## 0.5.2 — 2026-10-17

- 新增投影（TradingView 的扇形：起点、未来点、估计价格，标注涨跌幅）与幽灵 K 线（逐点点击设想路径，双击或 Enter 结束；从首点到末点每个 K 线周期一根，收盘跟随路径；每根高低差取其实体与「路径起点前 20 根真实 K 线平均高低差 × 0.6–1.4 的固定抖动」中的较大者，最多 2000 根。TradingView 未公开其生成算法，这是近似实现）。共 74 种。
- 查证 TradingView 帮助页后记录：内部叉子线的官方描述与改良 Schiff 相同、固定江恩方格没有说明文档，两者未做；锚定文本与表格仍未做。

## 0.5.1 — 2026-10-17

- 再补 6 种 TradingView 画线（共 72 种）：荧光笔（拖动绘制的半透明粗线）、路径（逐点点击，双击或 Enter 结束，末端带箭头）、折线、图钉（带说明）、斐波那契螺旋（每四分之一圈放大 1.618 倍）、K 线形态（把源区间的 K 线按首根开盘价对齐复制到指定位置）。
- 仍未做：内部叉子线、幽灵 K 线、投影（未确认其精确定义）、固定江恩方格、锚定文本、表格。

## 0.5.0 — 2026-10-17

- 新增 25 种 TradingView 画线（共 66 种）：平顶 / 平底通道、分离通道；斐波那契速度阻力扇、斐波那契圆、速度阻力弧、楔形、基于趋势的斐波那契时间；Cypher、三驱、三角形态、艾略特三角浪 / 双重组合 / 三重组合、周期线、正弦线；椭圆、旋转矩形、弧线、曲线；便签、价格便签、路标；预测、锚定 VWAP（HLC3 × 成交量，从锚点累计到最新 K 线）、锚定成交量分布。都支持拖动编辑、样式、撤销、复制和 agent 画线。
- 画线菜单顶部加搜索框（按中文名、英文名或类型名过滤）。
- 修复：选中靠近图表顶部的画线时，浮动工具条压住它的锚点导致拖不动；现在工具条放在遮挡锚点较少的一侧（顶部或底部）。锚点同时贴近上下边缘时仍可能有锚点被遮挡，可先平移或缩放图表。
- 锚定 VWAP / 锚定成交量分布的锚点早于已加载历史时自动补载，补齐前 VWAP 标注「数值暂不完整」。
- agent 的 `hyper_chart` points 说明列出每种画线的点数。
- 冒烟新增 tools2（25 种新工具真实绘制、菜单搜索、工具条避让）与 trackpad 阶段。

## 0.4.4 — 2026-10-17

- 修复：触摸屏上无法画线。lightweight-charts 处理轻点时会在 touchend 上 preventDefault，浏览器不再补发 click，而落锚点依赖原生 click；现在未拖动的触摸 pointerup 直接按点击处理（同一轻点之后若仍有 click 会被忽略）。
- 修复：手指拖动锚点或画线时被浏览器当作页面滚动而中途取消（pointercancel）；图表区域设为 `touch-action: none`，与 TradingView 一致由图表处理全部手势。
- 冒烟新增 touch 阶段（点画、选中、拖锚点、单指平移）。

## 0.4.3 — 2026-10-17

- 趋势线可分别向左、向右延长（浮动工具条两个开关，agent 工具 `extendLeft` / `extendRight`）；价格提醒按延长后的线判断，延长的线不参与屏幕外剔除。
- 「点击没反应」根因补充验证：0.1.0 两次点击间隔 300ms、450ms 同样漏画 20/20，550ms 0/20，分界与图表库 500ms 双击窗口一致；当前版本同样间隔 0 漏画。

## 0.4.2 — 2026-10-17

- 画线对象属性对齐 TradingView：按周期显示（仅本周期，水平线的轴价格标签同样隐藏）、文本与标注气泡字号（10–32px）与粗体 / 斜体、矩形 / 圆 / 三角 / 通道 / 斐波那契 / 区间等的背景填充浓淡；浮动工具条、agent 工具参数、撤销与复制都支持。限定周期的画线在其他周期不绘制但保留在画线列表。
- 浮动工具条加入「隐藏」，并固定为一行（窄图表上原先会折成三行、挡住图上方的画线）。
- 新增 `docs/tradingview-drawing-checklist.md` 逐项对照（通用交互、对象属性、工具分组）。
- 修正「点击没反应」的根因说明：lightweight-charts 在 500ms 双击窗口内不为第二次点击触发单击回调；原生 click 路径已修复（0.1.0 对照：间隔 100ms 漏画 20/20、700ms 0/20）。

## 0.4.1 — 2026-10-17

- 屏幕外剔除：完全位于可视区之外的有限范围画线不再渲染（会延伸到边缘、超出锚点，或带标签 / 提醒 / 同步徽章的画线不剔除；选中的画线不剔除）。
- 经 codex 审核：撤销成交量分布的独立命中区域，保持区间空白处可拖动平移、价位文字可点击。

## 0.4.0 — 2026-10-16

- 首次见面先交付价值：系统提示按状态动态出现（档案为空时先做交易体检或市场雷达、实盘持仓没有足量止损时列为最高优先、连亏 3 笔时建议冷静期），并附一张交易卡模板；整段约 1000 token。
- 新增交易体检 `hyper_account action=analyze`：按完整往返统计胜率、盈亏比、期望、持仓时长，按币种 / 时段 / 星期拆分，计入手续费与资金费，并按金额列出习惯问题和建议规则；少于 10 笔往返时不下结论。
- 新增市场雷达 `hyper_market action=scan`：扫描成交额最大的核心永续与 HIP-3，给出贴近 / 突破 20 根已收盘 1h 区间、资金费极值、24h 涨跌与溢价的前几名。
- 价格提醒触发时唤醒画线所属会话的 agent（只复核和告知；去重、5 秒合并、5 分钟冷却、过期丢弃；被提醒唤醒的一轮不能下单、改限额或划转）。修复 HIP-3 市场的价格提醒从不触发。
- 在交易台「签名与托管」中连接钱包：选择签名方式、dsh-web3 账户并填写主账户地址，保存后立即生效，无需重启宿主，并在重启后保留。
- 对话栏快捷入口改为：交易体检、今天有什么机会、帮我盯着仓位、把图上画线变成策略。
- 行情实时更新不再整批重设序列、不再重建画线坐标映射，翻译函数缓存语言；5000 根 K 线 + 100 条画线下实时更新的 p95 帧耗时由 133ms 降到 16.7ms。
- 研究多图首次加载时以联动范围为准，修复完整流程中的时间联动失败。
- 新增 `docs/agent-evals.md` 评测场景与评分表。
