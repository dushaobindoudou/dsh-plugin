# dsh-whatsapp

[![npm](https://img.shields.io/npm/v/dsh-whatsapp.svg)](https://www.npmjs.com/package/dsh-whatsapp)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](#license)

**WhatsApp channel bridge for dsh bots** - a plugin for the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`).

This package name is reserved; the first release is in development.

The world-default messaging lane - bot digests and customer conversations over the Cloud API, template messages for alerts, human handoff on low confidence. Registered externally; promoted into the curated core.

Source and roadmap live in the [dsh-plugin monorepo](https://github.com/dushaobindoudou/dsh-plugin).
Watch the repo or the npm package to catch the release. Related releases from
the same suite: [dsh-workflow](https://www.npmjs.com/package/dsh-workflow),
[dsh-selfrepair](https://www.npmjs.com/package/dsh-selfrepair),
[dsh-finder](https://www.npmjs.com/package/dsh-finder).
