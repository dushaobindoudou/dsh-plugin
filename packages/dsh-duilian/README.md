the same suite: [dsh-workflow](https://www.npmjs.com/package/dsh-workflow),
[dsh-selfrepair](https://www.npmjs.com/package/dsh-selfrepair),
[dsh-finder](https://www.npmjs.com/package/dsh-finder).
